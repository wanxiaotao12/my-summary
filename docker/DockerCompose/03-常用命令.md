# Docker Compose 常用命令

注意：以下命令均在 `docker-compose.yml` 文件所在目录执行。

## 命令格式

```
docker compose [选项] <命令> [服务名]
```

- **选项**：全局参数，常用选项如下：

| 选项 | 说明 | 示例 |
|------|------|------|
| `-f` | 指定配置文件路径（默认读取当前目录下的 `docker-compose.yml`） | `docker compose -f my-compose.yml up -d` |
| `-p` | 指定项目名。项目名用于生成容器、网络、卷的前缀，默认使用 `docker-compose.yml` 所在目录名。注意：若服务配置了 `container_name`，则容器名直接使用该值，不受项目名影响 | `docker compose -p myapp up -d`，未配置 `container_name` 时容器名将为 `myapp_服务名_1` |
- **命令**：要执行的操作，常用命令如下：

| 命令 | 说明 | 示例 |
|------|------|------|
| `up` | 创建并启动服务容器。执行逻辑：<br>1. 若配置 `build`，先构建镜像<br>2. 若配置 `image`，检查本地是否存在，不存在则从仓库拉取<br>3. 基于镜像创建并启动容器 | `docker compose up -d` |
| `down` | 停止并移除容器、网络（保留卷） | `docker compose down` |
| `start` | 启动已存在的停止状态的容器 | `docker compose start` |
| `stop` | 停止运行中的容器（不删除） | `docker compose stop` |
| `restart` | 重启服务容器 | `docker compose restart` |
| `ps` | 查看服务容器状态 | `docker compose ps` |
| `logs` | 查看服务日志输出。不指定服务名时输出所有服务日志,指定服务名时仅输出该服务日志 | `docker compose logs -f` |
| `exec` | 在运行中的容器内执行命令 | `docker compose exec nginx sh` |
| `build` | 构建或重新构建服务镜像 | `docker compose build` |
| `pull` | 拉取服务依赖的镜像 | `docker compose pull` |
- **服务名**：可选。指定时只对单个服务生效；不指定则对所有服务生效

## 启动 / 停止 / 重启

```bash
# 启动所有服务（-d 表示后台运行，不占用当前终端）
docker compose up -d

# 启动指定服务
docker compose up -d <服务名>

# 停止并删除所有容器和网络（卷默认保留，加 -v 连同卷一起删除）
docker compose down

# 重启所有服务
docker compose restart

# 重启指定服务
docker compose restart <服务名>
```

## 查看状态

```bash
# 查看运行中的服务
docker compose ps

# 查看服务日志
docker compose logs

# 实时跟踪日志
docker compose logs -f

# 查看指定服务的日志
docker compose logs <服务名>
```

## 构建镜像

```bash
# 构建所有服务的镜像
docker compose build

# 构建指定服务
docker compose build <服务名>

# 不使用缓存构建
docker compose build --no-cache
```

## 执行命令

```bash
# 在运行的容器中执行命令
docker compose exec <服务名> <命令>

# 进入容器的交互式终端
docker compose exec -it <服务名> /bin/bash
```

## 其他命令

```bash
# 查看版本
docker compose version

# 配置校验（检查 yml 文件语法是否正确）
docker compose config

# 暂停服务
docker compose pause

# 恢复服务
docker compose unpause

# 删除服务产生的数据卷（加 -v）
docker compose down -v
```
