### 标准命令格式
<font style="color:rgb(82, 82, 82);">其命令格式为：</font>

```bash
docker pull [选项] [Docker Registry 地址[:端口号]/]仓库名[:标签]
```

<font style="color:rgb(82, 82, 82);"></font>

<font style="color:rgb(82, 82, 82);">具体的选项可以通过 </font><font style="color:rgb(82, 82, 82);background-color:rgb(247, 247, 247);">docker pull --help</font><font style="color:rgb(82, 82, 82);"> 命令看到</font>

<font style="color:rgb(82, 82, 82);">Docker 镜像仓库地址：地址的格式一般是 <域名/IP>[:端口号]。</font>

<font style="color:rgb(82, 82, 82);background-color:#FBDE28;">如果不填写，默认是 Docker Hub(docker.io)。 </font>

<font style="color:rgb(82, 82, 82);">仓库名：如之前所说，这里的仓库名是两段式名称，即 <用户名>/<软件名>。对于 Docker Hub，如果不给出用户名，则默认为 library，也就是官方镜像。</font>

## 如何修改镜像的tag
修改 Docker 镜像的 `tag` 其实就是给镜像重新打一个标签（tag）。这并不会修改镜像本身，而是创建一个新的标签引用， 使用docker images时会展示2条， 一条是原来的tag， 另外一条是重新打的标签



假设你有一个镜像，当前标签为 `nginx:latest`，并且你希望将其修改为 `nginx:v1.0`，你可以运行以下命令

```bash
docker tag nginx:latest nginx:v1.0
```



这会给原来的 `nginx:latest` 镜像添加一个新的标签 `nginx:v1.0 ` ， 镜像的id是一样的。你可以通过以下命令查看新的标签：

docker images

<img src="https://cdn.nlark.com/yuque/0/2025/png/1929553/1740318676722-85839af2-5851-42f6-ba73-5eeff6e1cd1f.png" width="708" title="" crop="0,0,1,1" id="ue3d0b7c0" class="ne-image">



如果想删除以前的标签，则使用

docker image rm nginx:latest

或使用 docker rmi nginx:latest



## 删除镜像
### 命令
`docker image rm` 也是删除 Docker 镜像的命令，它的功能和 `docker rmi` 完全相同，主要是 `docker` 命令的不同命名方式。`docker image rm` 更加明确地表明操作的是镜像。



#### image rm
docker image rm <image_name_or_image_id>

#### rmi
_<font style="color:rgb(255,0,0);">docker rmi repository:tag </font>_

_<font style="color:rgb(255,0,0);">docker rmi imageID</font>_

_<font style="color:rgb(255,0,0);"></font>_

<font style="color:rgb(51, 51, 51);">docker rmi -f myimage:latest</font>

#### <font style="color:rgb(51, 51, 51);">区别</font>
`<font style="color:rgb(51, 51, 51);">docker image rm</font>`<font style="color:rgb(51, 51, 51);"> 和 </font>`<font style="color:rgb(51, 51, 51);">docker rmi</font>`<font style="color:rgb(51, 51, 51);"> 完全是等价的，只是语法上更加明确和规范</font>

<font style="color:rgb(51, 51, 51);"></font>

### <font style="color:rgb(51, 51, 51);">删除多个镜像</font>
```plain
docker image rm my_image1 my_image2

docker rmi my_image1 my_image2
```

### <font style="color:rgb(51, 51, 51);">强制删除：</font>
<font style="color:rgb(51, 51, 51);">如果镜像正在被容器使用，你可能需要使用 </font>`<font style="color:rgb(51, 51, 51);">-f</font>`<font style="color:rgb(51, 51, 51);"> 选项来强制删除镜像：</font>

```plain
docker image rm -f <image_name_or_image_id>

docker rmi -f <image_name_or_image_id>
```

### <font style="color:rgb(0,0,0);">删除所有镜像 </font>
_<font style="color:rgb(255,0,0);">docker rmi $(docker images -q)</font>_

## 退出容器
### exit
这将退出容器的交互式终端，但 **容器会继续运行**（如果你是以 `-d` 启动的容器，容器会在后台继续运行）。如果容器是通过 `-it` 启动的，退出后会返回到宿主机的终端。



### **使用 **`**Ctrl + P**`** 和 **`**Ctrl + Q**`** 组合键**
如果你想退出容器的终端并返回到宿主机的命令行，而不停止容器的进程，可以使用：

+ `**Ctrl + P**`，然后 `**Ctrl + Q**`

这两个快捷键组合会让你退出容器的交互模式并返回到宿主机的终端，而容器会继续在后台运行。
