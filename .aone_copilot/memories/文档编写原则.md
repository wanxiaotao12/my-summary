## 金字塔原理
- **结论先行**：先说结论，再展开论据
- **MECE**：相互独立、完全穷尽
- **SCQA**：情境(Situation) → 冲突(Complication) → 问题(Question) → 答案(Answer)

## 三要素
每个功能点讲清楚：
1. **作用**：这个功能做什么
2. **为什么**：为什么要这个功能
3. **执行后状态**：执行后系统/数据变成什么样

## 七大表达规范
1. **定义前置**：核心概念先定义，再展开论述
2. **由浅入深**：先讲基础，再讲依赖它的高级内容
3. **用词精确**：用词准确无二义，表达清晰易理解
4. **术语统一**：同一概念全文使用同一术语，不混用
5. **读者友好**：讲人话，术语有解释，假设有说明，新人能读懂
6. **举例支撑**：抽象概念配具体示例，降低理解成本
7. **表达简洁**：不啰嗦，一句话能说清的不用两句

## 格式规范
- 使用 Markdown 标准语法
- 标题层级从 # 开始，不跳级
- 代码块标注语言类型
- 表格对齐

## 禁止项
- 禁止使用模糊指代（"这个"、"那个"、"它"指代不明）
- 禁止学术腔、官腔
- 禁止术语不解释
- 禁止同一概念多个名称混用

## 写作检查清单
- [ ] 结论是否先行？
- [ ] 概念是否定义前置？
- [ ] 术语是否全文统一？
- [ ] 抽象概念是否有示例？
- [ ] 表达是否简洁无冗余？
- [ ] 新人能否读懂？
