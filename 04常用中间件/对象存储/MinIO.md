# 对象存储中间件

## MinIO

### 简介
MinIO是一个开源的高性能对象存储服务器，提供兼容 Amazon S3 的 API。
- 基于 Go 语言开发
- 支持 HTTP/HTTPS 接口
- 采用 Apache 2.0 开源协议

### 部署方式
- **部署位置**：企业内部私有化部署 / 云端部署
- **部署规模**：单机部署 / 分布式多机部署
- **部署环境**：本地服务器 / 云主机 / 容器化（Docker/Kubernetes）

### 客户端

#### 1. Web 控制台
- MinIO Console：内置的图形化管理界面
- 默认端口：9001（新版本）或随 API 端口自动分配
- 支持文件上传下载、桶管理、用户权限管理

#### 2. 命令行工具（CLI）
- **mc**（MinIO Client）：官方命令行工具
  - 支持文件管理、桶操作、镜像同步
  - 兼容 POSIX 命令风格（如 `mc ls`、`mc cp`、`mc rm`）
  - 支持跨云存储迁移

#### 3. SDK（多语言支持）
- **官方 SDK**：
  - Java
  - Python
  - Go
  - JavaScript (Node.js)
  - .NET
  - Ruby
- **第三方 SDK**：
  - 任何兼容 AWS S3 的 SDK 都可使用（如 aws-sdk）

#### 4. API 接口
- **RESTful API**：兼容 Amazon S3 API
- 支持的操作：
  - PUT/GET/DELETE 对象
  - 创建/删除桶
  - 分片上传
  - 预签名 URL

#### 5. 其他集成方式
- **FUSE 挂载**：通过 s3fs 等工具将存储挂载为本地文件系统
- **网关模式**：作为 NAS、HDFS 的 S3 兼容网关
- **Kubernetes CSI 驱动**：作为持久化存储卷

### 核心特性
- **高性能**：读写性能优异，支持大规模并发
- **分布式**：支持多节点集群，数据自动分片和冗余
- **纠删码**：即使丢失一半节点，仍可恢复数据
- **加密**：支持服务端加密（SSE）和客户端加密
- **生命周期管理**：自动过期、转换存储层级
- **版本控制**：支持对象多版本管理
- **桶策略**：细粒度的访问控制
- **事件通知**：支持 Webhook、Kafka、RabbitMQ 等

### 常见使用场景
- **私有云存储**：企业内部搭建类 S3 存储服务
- **数据湖/大数据**：作为 Spark、Presto、Flink 的数据源
- **备份与归档**：数据库备份、日志归档、文件存储
- **AI/ML 场景**：存储训练数据集、模型文件
- **静态资源托管**：图片、视频、文档等静态文件存储
- **微服务架构**：作为文件服务的统一存储层

### 同类对比
| 中间件 | 特点 | 适用场景 |
|--------|------|----------|
| **MinIO** | 轻量、高性能、S3 兼容 | 私有云、容器化、中小规模 |
| **Ceph** | 功能全面（块/文件/对象） | 大规模企业级、需要统一存储 |
| **SeaweedFS** | 轻量级、简单易用 | 小文件存储、快速部署 |
| **阿里云 OSS** | 公有云服务 | 无需运维、弹性扩展 |
| **AWS S3** | 公有云服务 | 云上应用、全球化部署 |

### 常用端口
- **9000**：API 端口（默认）
- **9001**：Web 控制台端口（新版本）

### 快速启动示例
```bash
# 单机模式启动
minio server /data

# 指定端口启动
minio server --address :9000 /data

# 分布式部署（4节点示例）
minio server http://node{1...4}/data
```
